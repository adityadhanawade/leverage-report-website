# Learning Track — Understanding This Codebase

A 10-lesson study path through the real code in `website/`, written for someone
learning React/Next.js for the first time. Every lesson quotes actual files from
this project — no toy examples.

Total app size: ~2,360 lines across 33 files.

## Lessons

| # | File | Topic |
|---|---|---|
| 1 | [01-the-stack.md](01-the-stack.md) | What Next.js / React / TypeScript / Tailwind each actually do |
| 2 | 02-routing.md | Files → URLs (the App Router) |
| 3 | 03-components-and-jsx.md | What a component is; props and children |
| 4 | 04-typescript.md | Types, and what they prevent |
| 5 | 05-server-vs-client.md | The `"use client"` boundary |
| 6 | 06-state.md | `useState` and interactivity |
| 7 | 07-logic-vs-ui.md | Why `lib/` exists separately from `components/` |
| 8 | 08-styling.md | Tailwind v4 and the design tokens |
| 9 | 09-the-backend.md | API routes, server-only secrets, MailerLite |
| 10 | 10-build-and-deploy.md | `next build`, static vs dynamic, Vercel |

## How to use this

Read the lesson, then open the real file it quotes and read that too. Each lesson
ends with an exercise — do it before moving on.
